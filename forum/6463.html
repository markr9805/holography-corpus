Colin Kaminski Thu Sep 27, 2007 11:59 pm #2
You can expand the beam with a convex mirror, or a -FL lens. It does take space. 50 CM does not sound to bad but if you have to you can get faster lenses or mirrors.

You only need to collimate (make parallel) the beam if you are using the hologram for a special purpose. The final display hologram needs to be made with a point source. So if you are making a single beam reflection then you only need the laser and one lens.
Tom B. Fri Sep 28, 2007 12:47 am #3
Sources of small, short focal length optics:

- Telescope eyepieces, microscope eyepieces and objectives. Simple non-achromat lenses from toy versions are OK if not made of plastic since the laser is a single color. The higher the power, the shorter the focal length of the lens.

- Junked point-and-shoot cameras - viewfinders and primary lenses. Sometimes you can find small beamsplitters in them, too.

- Shiny ball bearings (preferably new, unused)

With all of these you will notice that tiny dust specks and imperfections on the surfaces are VERY noticeable when magnified in the expanded beam, but it's OK for getting started.

Colin Kaminski Sat Sep 29, 2007 1:15 pm #7
> Dominik Hangleiter: You only need to collimate (make parallel) the beam if you are using the hologram for a special purpose.What kind of special purpose are you thinking of?

Using the real image from a transmission hologram is the best example. To get the real image of a transmission hologram you need to flip the plate for illumination. Since the illumination is now coming from the opposite side as the original reference beam it reduces aberrations to have the reference and the illumination beam collimated.
