I think it might be interesting to cover a white object with DCG, then let it cure. Expose the entire object to a single reference beam then process. I belive it should display some nice reflections. Of course then it would have to be sealed but that is another story. I also wonder how the reflection would be seen, all at once or just color reflections from different angles corosponding the the object angles. Just a thought.
