Looks good! I assume this is a single-beam reflection H1 (Denisyuk)? I found it hard to get good brightness on this type of holo with the Fuji film, but H2s where I could control the beam ratio were better. I assumed it was because the dyes seem to absorb a lot of red light, not leaving as much for the object as I would like for a Denisyuk. Maybe I should give it another try, varying exposure and chemistry more carefully this time...
