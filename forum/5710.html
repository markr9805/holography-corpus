Let's say long ago one created a Master Transmission hologram that was made with a diverging beam and because it was so long ago the divergent rate is unknown. Now one wants to make an H2 image planed reflection from the master and wants to correct for the diverging reference beam of the H1 by using a conjugate (converging) object beam for the copy.

Is there any way to do tests or a procedure which will show what the original divergent rate was? Do you think it would be possible to illuminate the H1 with slightly different angles from one side of the plate to the other with a raw beam until both produce a sharp image at the same plane to determine the divergent rate? Or is there an alternate technique to find this out?

Obviously making hologram after hologram starting with collimated and moving toward a more converging beam for each hologram would be lengthy and costly.

Any ideas?
Kaveh Fri Jul 21, 2006 4:01 pm #2
Easiest way might be a "no parallax" method. Try and replay the hologram with the reconstruction beam near the correct position and angle with regards to the H1. If the image looks magnified, then bring the beam closer. Rotate the H1 till distortion is minimized. Now you are close to the original geometry.

To fine tune, put a point object coincident with an image point. For instance put a tip of a pin or needle at a recognizable highlight point in the image. Have enough light on the point object so that the image and the point are both visible.

Now move your head side to side and up and down, and see if the image point moves with respect to the point object. If it does, there is some aberration in the image. Now move the reconstruction point back and forth, and adjust tilt of hologram, till the aberration is minimized.

When you hit the perfect geometry, there should be no image "swing" anywhere.

Now you can measure the geometry and produce a corresponding converging beam.
