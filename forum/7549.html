Glenn Thu Oct 09, 2008 2:34 am #9
> Colin Kaminski: I am not familiar with QinetiQ's work.QinetiQ's Active Tiling system is a CGH modulator that requires conversion of an analog pixel array distribution into a binary distribution, with minimum degradation in the replayed image.Would this not create harmonic noise seen in multiple orders?

Quinti-Q is a British defense contractor. Their Active Tiling system can create a screeen that easily supports 25M + pixels. It does this very simply. You have the following things:

1. An EASLM.

2. OSLM

3. Lens array (array of little convex lenses--5 x 5)

4. Shutter array.

The idea is simple enough. Render on the EASLM (which is 5M x 5M LCD) a part of the holographic diffraction pattern. Just one part out of 25 parts, to be exact. Then, use the shutter to render the next diffraction pattern on each successive parts of the OASLM, for an image total of 5 x 5 diffraction patterns.

Since each diffration pattern is from a 5M x 5M LCD, you get a screen resolution of 25M by 25M pixels.

[http://www.freepatentsonline.com/6927748-0-large.jpg](http://www.freepatentsonline.com/6927748-0-large.jpg)
