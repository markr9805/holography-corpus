please excuse the roughness of this hologram as im now taking baby steps!LOL

Here are my latest results;

This is a double exposed hologram, covering one mask per exposuer, with color tuning bath in between.

![Image](http://members.aol.com/addiemae910/dcg2cb.jpg)

After 30 test shots im starting to get a feeling how this need to go;

Using an H2 configuration (proximity copy)seems to work better in holding onto the first image(green),if only H1 configuration is used the image seems to fade to easily.

When trying to balance the image intensity, I have found the second exposure requires less energy than the first like 10% less (using H1 type configuration), this may not hold true when using a H2 setup due to intense energy at th film plane.

I’m losing to much sensitivity (dichromate) into the first "first color tuning bath. A fix to this problem might be to add a little dichromate to this bath or possibly a thicker gelatin coating?

I have not really seen any DCG psudo color papers published ...
