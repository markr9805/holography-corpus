jeff-blyth Thu Jun 08, 2006 8:26 pm #5
> JohnFP: Hummm, a harmonic coherence. Does that exist? If so can it be calculated and used?

Yes it certainly can. About 25 years ago on a ~10ft long table I once needed to make a real image 2 beam reflection H of a small model railway engine so that the image would finish up postage stamp size for a pop group's record label. I think that meant a size reduction by a factor of 2. I had a large high quality lens but its focal length was about the same as the HeNe's coherence length (~14inch) which meant that a same size real image was produced about 28 inches away and reduced size still further away. The fortunate fact is that the coherent region keeps recurring at multiples along the table (and back if reflected from a mirror). But unlike a "harmonic effect" it does not seem to diminish or become drastically less efficient over distance . So I had about a 10 inch reference beam length and several feet of object beam length from a 14-inch-only coherence length laser(ie only 7 inch depth when used on a standard Denisyuk single beam system.)
