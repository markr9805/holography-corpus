DMD SPATIAL LIGHT MODULATOR

DEVELOPMENT SYSTEM

1. This advanced, stable and volume-produced DMD Driver Board

can supply the conventional Computer Digital Interface DVI

(Without noise and analog interference) and Analog VGA Input;

2. The DMD Micromirror can rotate with input signal. It is widely

used in Lithography, Laser Hologram, IR Dynamic Thermal

Imaging System and Advanced Laser Optics Experiments and

High Performance Laser LED Projection system, etc. applications.

It can support signals with high frame frequency (Up to SVGA

(800X600)@200HZ or XGA (1024X768)@150HZ) input signals

from computer display adaptor cards as we have tested;

3. The switching of the DMD Micromirror is very fast. It has high

brightness and contrast (at least 2000:1 with proper optical

systems) and high reliability (400 thousand hours MTBF). It can

work in Visible light, IR light and UV light under –55 Cent

Degree. The illumination light sources can be Laser, LED and the

conventional lamps. It can also be used as high speed spatial light

modulator independently;

![DMD.jpg](https://holographyforum.org/forum/download/file.php?id=6590)

4. The system support freeze DMD Micromirror, Flip the image

(Left and Right, Up and Down);

5. We can supply the new arrival DMD with native resolution

1024X768 with the aspect ratio 4:3. This is the point-to-point

relationship with conventional computer output without any

distortion.

6. We can also supply the premium DMD with native resolution

800X600 with the aspect ratio 4:3;

7. XGA (1024X768) DMD has two superstructure, one is 13.68

Micrometer with diagonal size 0.7 inches; the other one is 10.8

Micrometer with the diagonal size 0.55 inches. This driver board

can support both of them with different firmware on the board;

8. The controller software is based on Windows XP operation system

with USB driver Interface. Programming with Visual C++ 6.0, it

is easy for expansion for high precision experiments. We can also

support IR remote controller;

9. We have independently Designed This system. For the software

and hardware systems, we can supply the tailored services for

customers and in fact, we have done this.
