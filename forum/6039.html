Interesting work, thanks for sharing it.

In my opinion, it should be possible to do such long exposures on MBDCG in the split-beam reflection format as well, if enough care is taken to stabilize the setup. What do you think, Kris?

My plans are to use stable objects and mounts, along with the shortest beam paths possible after the beamsplitter (using a highly diverging reference beam, and doing likewise for the object beam). Also using a table with minimal thermal expansion (granite), temperature and draft control, etc.
