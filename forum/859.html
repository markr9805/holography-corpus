Hi John.

Osram claim that the diode runs in single transverse mode, not single longitudinal mode (SLM). We need both for holography.

Wler, a member of this forum, has done a number of tests on laser diodes, his recent tests also include the Osram PL520. The results can be found here:

[http://redlum.xohp.pagesperso-orange.fr ... ml#summary](http://redlum.xohp.pagesperso-orange.fr/laser/modeanalysis.html#summary)

[http://redlum.xohp.pagesperso-orange.fr ... html#PL520](http://redlum.xohp.pagesperso-orange.fr/laser/ECDL-test.html#PL520)

Steven.
