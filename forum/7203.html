JohnFP Thu Mar 13, 2008 11:31 am #3
Hey Justin, how's it going?

It is actually a 6" collimator. This was in the beginning for DCG and I was only doing 4x5 plates. So a 6" collimator was plenty for this camera.

I try to use a collimated beam for SBR if the optics allow. Using a collimated beam allows your SBR to be used as a master for iamge planed proximity copying.

On a side note, if you don't have a collimator, placing your objective as far away from the plate as possible helps.

I would have to say that, and this is probably only a slight advantage, that using a collimated or better still a converging beam will increase the amount of light slightly to the object resulting in more object light. But I bet it is very slight unless a highly converging beam is used with an object a few inches from the plate. (Man, this is a good thought and one that should be confirmed). Wonder if the trade off is worth it.

No I did not use any kicker mirrors in this set up but YES, YES, YES kicker mirrors definitely help in a SBR.

When you start SBR's in DCG I will point out you can add additional lighting right through the plate. Much easier for those objects that are close to the plate.

Peace!
