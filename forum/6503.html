JohnFP Mon Oct 22, 2007 1:42 pm #2
> Is the angle important at which the object beam hits the object ?

Not at all unless the object is specular in its reflections (mirror like or very glossy).

If you are getting two beams from the beams spitter to the lens and ultimately to the plate for the reference beam, this could cause some problems. First, the reading of the intensity at the plate for the reference beam will be lower then it actually reads because in essence you are trying to make two holograms, one with each beam. If you are having problems with the double reflection still from the beam splitter, use the through beam, which will not have the double reflection for the reference beam and the reflected (double) beam for the object beam. The object can have multiple beams illuminate it with no issues.

Also, take a peak at polarization of both the object beam (look at the object through a polarizer after it is illuminated) and reference beam. Insure your not getting a big fall off in light ratio's. Most people forget that it is only polarization oriented in the same direction that interfer. If polarization is off by 45 degrees, then 1/2 fringe intensity. If polarization is off by 90 degrees then no fringes at all. Most object randomly polarize the beam so the usable object light for holography is usually about half of the light actually hitting the object.

If you have a high mounted object, take a heave piece of steel bar or something and mount it from the top of the optic mount or as close to the top as possible to the table at a angle. This will greatly help in stability.

Yes, but to be sure we are on the same page;

![overheadmirror.JPG](https://holographyforum.org/forum/download/file.php?id=5957)

For polarization. Take a polarizing filter and place it in the reference beam just before the plate. Rotate it until the beam is the brightest. Then place the polarizing filter in the object beam just before the plate making sure the orientation is the same (do not rotate the polarizer). Now, note the brightness of the object beam. Finally, take the polarizer, still in the object beam and rotate it 90 degrees clockwise then back, then 90 degrees counter-clockwise then back. Is the origianl position the allow the brightest object beam? You can use some polarizing sun glasses to do this.

But rarely do you have to worry about polarization with a diffusing object as those objects randomly polarize the object light anyway, so do not get too hung up on that.

My biggest focus for you is to set back up that Michelson and keep working to get that nice and stable. If you cant get the fringes to stablize in a Michelson, then you will not get a hologram with any split beam set up.

JohnFP Wed Oct 24, 2007 4:45 pm #6
Yes, you can use anything reflective to get overflow light back to a diffusing object. Even a regular mirror or aluminum foil, provided it does not move at all. Remember, once the light hits the kicker mirror and then is redirected to the object, the kicker mirror is the (beam Splitter) and the secondary lighting is acting as a split beam. So rigidity is of utmost importance or you will not see the benifits of the addition light from those kicker mirrors.

What I have done to insure the overflow light from the kicker is actually working is to block half the secondary light from the kicker and make a hologram. You should see the shadow where half the kicker is blocked on the object.

This will make your Denisyuks brighter.
