lobaz Wed Oct 09, 2013 5:00 am #2
Hi,

a few years ago my colleagues completed a set of tools "Digital Holography Toolkit". It is available here:

[http://www.kiv.zcu.cz/en/research/downl ... dukt_id=31](http://www.kiv.zcu.cz/en/research/downloads/product-detail-en.html?produkt_id=31)

(If the page does not display in English, try to locate "Digital Holography Toolkit" from [http://www.kiv.zcu.cz/en/research/downloads/](http://www.kiv.zcu.cz/en/research/downloads/))

Since then, various advanced techniques have been implemented. I also make my own software to test various ideas in CGH, mainly light propagation for CGH. However, these tools are not available as a full package including documentation, examples, binaries etc.

So: try a toolkit that is a bit outdated but works fine. Is you are interested to have a current version of a software that is permanently "work in progress", PM me.

By the way, I know that Kyoji Matsushima offers his WaveField Tools for download:

[http://www.laser.ee.kansai-u.ac.jp/WaveFieldTools/](http://www.laser.ee.kansai-u.ac.jp/WaveFieldTools/)

However, I did not try it.

Petr
