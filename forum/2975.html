Colin Kaminski Wed Dec 22, 2004 5:53 pm #2
I don't know of an on line source but all of the math can be found the the excellent book:

Optical Holography by P. Hariharan

[http://search.barnesandnoble.com/bookse ... XT=Y&itm=9](http://search.barnesandnoble.com/booksearch/isbnInquiry.asp?isbn=0521439655&TXT=Y&itm=9)

This is all of the math needed but it is not presented in a format that you can just write code to. You will need to understand why the math was derived then use the code. You will also want to have a FFT to use. Algorithms in C has an easy one to implement if you are working in the C environment. Or if you have lots of programming experience writing your own is actually a good exercises and will show you one of the more interesting historical problems in computing. If you have to you can just use a FT however the resulting code will take about 20 times as long to run.

For high spatial frequencies and complicated objects be prepared to run your code for months to generate a hologram. Most programs I see input simple objects and use very narrow angles between the object and reference beams to keep the computing down to a manageable level.

There is a different method called binary detour holograms. It is explained in this book as well. They suffer from the zero order washing out the image but the computing level is very small. I have not played with them but the examples in the book listed above are interesting.
