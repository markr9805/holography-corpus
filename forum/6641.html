Dave and John did side-by-side tests, and they found each as bright as the other. I should have done likewise, because I would like to see for myself.

One thing I can say is that on some of my recent DCG's (the ones with the Greek impression) the brightness while in the 91% was very substantial, and this was obvious. Looking back, I should have just tried drying this without the 99%. I know it would have been very bright, but side-by-side tests are needed to be sure. Even if the 99% does produce slightly brighter holograms, this would only be needed on holograms that should be "perfect." At least for the holograms I'm doing at the present time, this is not necessary.

On a sidenote, my current source for 91% is not especially cheap, because it only seems to be available in small sizes in stores around here.
