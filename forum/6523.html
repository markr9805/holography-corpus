I am trying to understand coherence length in how it applies to holography. Let me describe a fictional scenario and please tell me if this is the correct interpretation of CL:

Lets say I have a laser 532nm with a CL of 20cm. Lets say I am making a Split Beam transmission hologram. The reference beam path measures 2 meters in length, and the object beam path is 2.5 meters. A difference of .5 meter (50cm). Does this mean the coherent nature of the SPLIT beam is no longer "in sync" when they combine to create the interference pattern at the scene, and therefore will not produce an image? Alternately, say I have the above setup where reference beam and object beam lengths are within 20cm, does this allow for the proper interference at the scene?

Colin Kaminski Sun Nov 04, 2007 5:09 pm #2
For practical purposes, you will want to equalize the path lengths within a cm or two. That will give you 18 cm of usable object depth. Remember that the distance from the object to the plate needs to be added to the object path length.

What you say is basically correct, though you should realize that the coherence length is not very sharply defined. Rather, when the path difference between ref beam and reflected object beam _at the location_ of the plate becomes larger, the beams gradually get out of sync and the image gradually dims out. That is, if the size of the object is in the order of the coherence length or larger, then parts of the object away from the ideal location will gradually dim out. Thus the object should be considerably smaller than the coherence length, and the total path lengths should match considerably better than the CL. If you match the object beam path length by measuring from the center of the object to the center of the plate it should work out well.

If the coherence length is small, like 1 inch for an argon laser without etalon, then you need to match path lengths very precisely, to better than 1/4 inch or so, and the recorded depth of the scene (no matter how big the object is) will be in the order of an inch only.

walschuler Thu Dec 20, 2007 6:48 am #6
Two other points about path length difference, coherence length and image brightness:

1) Consider an ellipse and its 2 foci. If the beam splitter is at one focus and the plate is at the other, for any disposition of reference beam mirror and objects, in which the mirror and objects sit anywhere on the ellipse, the path lengths for reference and objects will be identical. If the objects are large, as mentioned above, then the object path lengths will vary with position on the objects.

2) But in the above setup, some objects will be closer to the plate than others, and so the closest ones will send more light to the plate, and that will affect their relative brightnesses. This can be reasonably compensated by adjusting the object reflectances so that the farthest objects are the most reflective.
