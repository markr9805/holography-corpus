Hans Wed Jan 17, 2007 4:20 pm #2
The magnification of a reflection hologram has all to do with the reference beam and the light that is used to view the hologram.

You could divide into three cases:

1] Reference beam divergence angle = View beam divergence angle: The hologram will re-play in the same size.

2] Reference beam divergence angle < View beam divergence angle: The hologram shows objects bigger.

3] Reference beam divergence angle > View beam divergence angle: The hologram shows objects smaller.

4] (Special case) Reference beam and view beam are parallel: Hologram re-plays at the same size. Using a parallel beam is the preferred method for recording and copying H1 holograms that need to be flipped to make objects appear in front of the hologram.
