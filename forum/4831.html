Right; and it is a priori not clear what the coherence length

actually is - it depends on the line width and on how many

longitudinal modes lase. Unless explicitly stated otherwise, I would

expect a generic DPSS laser to have multiple longitudinal modes

rather having a single mode only (which means that the coherence

length may be very small). As it takes extra effort to achieve

single mode operation, and since for a laser eg made for light show

applications the single mode feature is irrelevant, it is unlikely

that a given generic DPSS laser has been designed that way. So

better be careful with that one...perhaps try to ask the manufacturer.

Colin Kaminski Thu May 12, 2005 8:30 pm #11
From Tom B.

As a first approximation, coherence length = (wavelength ^ 2) / (2 linewidth)

e.g. for 670 nm center wavelength and line width (wavelength range) of 0.2 nm,

coherence length = (670 10E-9)^2 / 2*(0.2E-9) = 0.0011 meter

Exact value would depend on the shape of the line.

The frequency equivalent:coherence length = speed of light / bandwidth

e.g. for 1500 MHz, this is 3E8 / 1500E6 = 0.2 meter.

(Iovine's book had a typo in this equation, but his example was correct)

Math and example from Iovine, "Homemade Holograms", 1990.

> Sergio: DannyBruza wrote:<0.01nmis too shortThe linewidth is adequate and the beam diameter with the coupled beam divergence (<2.4mrad) indicate a TEM00 transversal mode. Very fine beam!You must be sure that linewidth is correct

It's not just the linewidth that is relevant - that is relevant

only if there is a single mode lasing. If there are several modes

lasing, then it is their relative spacing what determines the

coherence length.

If there is one mode lasing, then the coherence length is determined

by the line width. If there are two modes lasing, then the coherence

length is roughly L, where L is the resonator length. If three modes

are lasing, then the coherence length is roughly L/2 (because the

spacing between the modes has doubled). If N are lasing, then the

coherence length is roughly L/(N-1).

How many modes actually do lase in a given laser, is hard to know

beforehand, because it depends on the details of the construction

of the laser. There are some typical estimates for certain laser

types, like argon lasers without etalon have like 10 modes lasing,

means that the coherence length is in the order of an inch or so;

with etalon, there is only a single mode, and in this case the line

width determines the coherence length (which can be 100m or so).

As for DPSS lasers, I don't know typical numbers, but as said before,

I wouldn't trust that a random given DPSS laser would be single

mode if it is not expressly stated in the specs.
