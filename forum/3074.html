Tom B. Wed Jan 26, 2005 7:10 am #2
If it's any consolation, results of my early experiments with PFG-01 film were not much brighter - I had much better results with PFG-01 plates. I never did get satisfactory results with PFG-01 film, though others here have.

Subject suggestion: borrow a string of pearls (fake or real) - placed almost touching the plate they can produce gratifyingly bright results. Also sparkly Xmas ornaments are good. Try lots of things and you'll develop an instinct for what works best.
JohnFP Wed Jan 26, 2005 11:45 am #3
Paul, keep up the good work. Again, as Tom mentions and I have mentioned before, a red object is not a good color to use. Use a flat white object and place it as close to the plate as possible. Also, if you can, blosck off half the plate with a black opaque card thus leaving only half the plate open for exposure. Do an exposure then block of the other half and do a different exposure time. Then when you process you can see how exposure time effects the hologram quality. You could even do a test by laying the sandwiched film or plate flat on a piece of white rigid board and make a series of strips with different exposure times to see which exposure time is best. Make sure each strip is only exposed one time.

I made an object for just such tests which I will be using shortly.

![Image](http://www.sketchys.com/Holograms/HoloStuff/Drawings/pyracubes5.jpg)

This object encorportates not only the strips for different exposures but allows the monitoring of the different distances from the plate as another function of the exposure time. I will be using this to see which exposure times are best for each independent wavelength I will be using for the multi color hologram. I will make a complete test plate for each wavelength containing 5 independent exposure times.

The object above is made out of rigid, solid black foam board for the dividers and white squares I bought at the dollar store that were stranded in pairs for hair ties for girls. The are nice and white. My actual object only has a stair case on one side in each strip as when I was building it I realized light would not hit the second set of steps due to the reference beam incoming angle.

I set this object on the table and lay a plate directly on it. Then cover all but one strip and use an overhead beam at about brewsters angle. I expose. Then use a different set of blocker cards such that I can expose another strip while blocking the others, then repeat for all.

Have a great day!!!
