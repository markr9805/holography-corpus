Ok, I thought I would post my geometry as that seems to be the thing most unavailable for other holographers. My table is about 3'7" by 7'6". So squeezing in everything is trying.

Here is the H1 to H2 set up alone (I simultaneously have the H1 with two object lightings on the table with just a drop out of one beam splitter I can go from one to the other). This is for a side reference beam, I deleted the overhead reference beam as I am now using my 12.5" (sorry, it was not 16" but 12.5") collimator instead of the flat overhead mirror used in my single beam set ups. Notice there is no beam splitter. Just a flat front surface intercepting mirror. With the thow prior to the interception and after, a collimator is not needed for the reference beam for the H2 as it is pretty far back. The black line at the top of the beam is blocker. The intercepting mirror is at the bottom and redirects part of the beam to the H2. The variable beam splitter is one of those cheap ones that gave double reflections (thin) but in this set up that is not a factor. It is placed in the path of the reflected reference beam for the H2. Thus by turning the variable beam splitter I can lower or raise the light level of the reference beam intensity thusly changing the ration of ref:obj in the copy set up. Pretty simple but very effective.

Tony Fri Nov 24, 2006 1:05 pm #5
John-

Your geometry looks OK except for matching coherence length (CL). Looks like the path length for the H2 is much longer than for the H1. If your laser has very long CL, this is no problem, but matching CL in the copy setup is just as important as it is in the H1 setup.

Also, I typically shoot H1s with an overhead reference beam. Then for the copy setup I rotate the H1 90 degrees; rotate the laser polarization 90- degrees, and shoot it with side illumination and a side reference for the H2. I thought everybody did it this way...?

I see now that I miss read John's first two postings. I've found that my reference beam for H1 can be either overhead or from the side which I'm sure everyone already nows. I prefer a side reference beam because it gives me a lower center of gravity and greater stability. Either way though it doesn't have any thing to do with the reference beam for H2 other than possibly the setup path of the H1 reference beam getting in the way of the setup path for the H2 reference beam. You are absolutely right John that, assuming your real image is right side up relative to the table, a reference beam for H2 from underneath will give you overhead white light illumination.

At this point, one could bring up the problem of the wood grain effect when sandwiching film between glass plates, the orientation of p-polarization, and Brewster's angle, but my experience shows that when I use 8E75 or 649-F plates for sandwiching, the wood grain effect is essentially non-existant, probably because these plates are close to optically flat.
