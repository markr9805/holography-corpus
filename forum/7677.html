I got this formula from [http://silvergrain.com/labs/Print_Devel ... mmendation](http://silvergrain.com/labs/Print_Developer_Recommendation?title=Print_Developer_Recommendation)

It does not to be mixed in a A and B solution and I have found that it works just as good as the Ultimate safe holographic developer. I made on adjustment to the original formula in that I left the KBr out because I don't think that there should be KBr in a holographic developer. Development time is about 1.5 minutes.

Dimezone S 0.2g

ascorbic acid 6.0g

sodium sulfite, anhydrous 12.0g

sodium carbonate, monohydrate 30.0g

triethanolamine, 99% 5.0ml

salicylic acid 0.5g

water to make 1.0 liter

target pH 10.4 ± 0.2

Hans Fri Jan 16, 2009 10:56 pm #3
The inventor names it DS-14 on his web site, but since it has been adapted by omitting the KBr, perhaps we could name it DS-14H (with the H standing for holographic or high contrast).

According to the inventor it should last rather long because of the TEA and the Salicilic Acid. (Both chelating any metal ions that would accelerate the oxidisation of the Ascorbate otherwise) And there is therefore no need to keep the developing agent and the base separately before use.

Hans Wed Jan 21, 2009 9:53 pm #9
> Im wondering if this can be used for Divided Development (for even and deep development)

I have no idea, and I have mine mixed in one bottle. It will last for some time since I made a liter and I only need 50ml to develop several holograms. I once tried to do divided development with Pyrogallol and NaCO3, but without much success.

But this developer is not extremely fast. Ideal development time seems to be about 2 minutes for homemade emulsions. That's the same as with Ultimate developer. I guess if the emulsion were really hard a longer development time would be needed.

If you find it hard to find Dimezone S (can be bought from photo formulary), there is also a formula on the Silvergrain web site for using this formula with Metol (without the benefit of being hand-safe of course).
