GrahamS Sat Jan 26, 2008 5:37 pm #9
The term 3D field will always confuse, it is better to think of a 2D field incident on a plane with a 2D amplitude and phase variation, that's the total field. If the field came from a converging sherical wave the phase variation would also be spherical for example.

Here is one way to prove that the field can be represented as plane waves (each is of constant amplitude) to yourself:

Put a point source at the focal plane of a lens on the axis, at the other focal plane (back focal plane) you will have the fourier transform. A point source is like a delta function and has equal components in all frequencies (remember these are spatial frequencies not temporal ones) and so the intensity of the light in the back focal plane will be constant, this is a plane wave and you have created a collimated beam.

(aside: in the fourier plane the centre represents DC or no frequency, the edges the highest frequency the lens can image, high frequency means a fine structure in the object)

If the point source is moved off the optical axis then the intensity of the light in the fourier plane will still be constant however there will now be a linear phase gradient across the plane. This is exactly the same as saying the collimated beam now moves at an angle to the axis of the lens. If phase scares you think of water waves, the crests are all at constant phase.

So any point in one plane can become a plane wave in the other plane with an constant intensity and a phase gradient. So what happens if you take a planewave and stick it into a lens, well you inverse fourier transform it or focus it. So we take our point source, stick a lens in front of it to convert it to a plane wave, then add another lens and convert it back to a point. This is really just a 1:1 imaging system, a real object is a collection of point sources.

So to answer your question more specifically, as we know that all (well enough of) the light from the object ends up in the fourier plane then we know that the light in the fourier plane contains all the required information. We should then consider this fourier plane as being made up of point sources and we already know that each one of these will form a plane wave when it has passed through the second lens so the image we end up with is made up of a set of plane waves and should look just like the object.

Its a round about proof but I hope it explains further fourier optics and also gives a better understanding of "angular spectrum" which is exactly what the set of plane waves is.

Graham
