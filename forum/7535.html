Hi Everybody..

I'm doing some experiments with Photoresists. I would like to create a hologram of an object in single color - say in green. I would also like to repeat the same experiment with Stereogram setup as mentioned in Frank's website. I have done lot of rainbow holograms in photoresist plates but this thought is new for me.

BobH Mon Sep 22, 2008 2:21 pm #2
You could make an achromatic "Open Aperture" transmission hologram, and emboss it into green colored plastic. That should work for a stereogram as well.
