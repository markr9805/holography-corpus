HI,

Can anyone advise on using 3 rechargable C cell batteries instead of 2 non rechargable batteries.

My thinking is this; the operating voltage for the integraf laser is 2.8 to 4V, using 2 1.5 volt

batteries, after not much usage the voltage will drop below 2.8 and produce poor results.

But, 3 rechargable batteries at 1.2 volts would give 3.6 volts (well below the 4v maximum)

My only worrry is that this might shorten the life of the laser.

any advise would be very helpful.

Thanks, Rick.
Cristiano_Perrucci Thu Jan 04, 2007 9:57 am #2
If you want to lower the voltage, just put a silicon diode in series. If you are using a widely common 1N4007, the voltage will decrease of ~0.7V. If you are using almost any fast diode (schottky diode) as the 1N58xx series, the voltage will drop of ~0.4V.
