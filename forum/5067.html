MichaelH Fri Sep 16, 2005 11:22 am #2
I see two problems.

1) Either the objects will need to be small and the lenses extremely short focus or you're going to need a 6-8" collimating mirror.

2) You can probably dispense with the first mask as the light going directly through the cylinder "slit" will miss the plate. You might get a little scatter from the edges of the cylinder lens but you'd save more light by using the mirrors as the mask.

3) The mirrors can't be attached flat to the lens assembly they'll have to be at a different angle such that they reflect back on the object. You might have been saving time when drawing but imo you might as well go to the trouble of making it as geometrically correct as possible, as early as possible.

Why are you using the cylinder lens and the liquid filled lens? I don't have my references with me but it occurs to me that you're just "un-slitting" the image and turning it into a one-step image plane transmission with little rainbow properties

Ed Wesly Mon Sep 19, 2005 1:04 pm #11
Here are some things to consider before ordering that "custom optic".

Cylindrical lenses have a focal length in one dimension. That means that they have magnifying power in only one dimension.
> The light from the object bounes off the object and is focused to a horizontal slit by the cylindrical lens.
is somewhat erroneous. The "slit" is an image that is compressed due to magnification in that one dimension, with the other dimension not diminished.

The best way to see this is with of course a positive cylinder lens, the Edmund 250 mm being the one most likely to be found in a holo lab. A tumbler filled with water, but with parallel sides, will sort of work, but because it would have such a short focal length it might be hard to work with.

Light an object up well, I looked at a desktop fan lit from behind since it has horizontal, vertical and a few angles inbetween vanes on it. It doesn't have to be laser for the light source to do the demo. Move a ground glass on the opposite side to find the image. There will be a point when the image will be narrowest. This is the vertical focal plane if the lens is held horizontally, as in the image lost by the server.

It will look pretty blurry at this point, with no object details readily apparent. To see the focussing action in only one direction, "stop down" the lens by covering almost all of the lens so that there is only a few millimeters being used. This eliminates most of the skew rays that are causing the fuzziness, so you can see the focussing in one plane.

Let's assume that the desired magnification is 1:1 life size at the holo image plane. This means that object distance = image distance = twice the focal length. So the first cylinder lens is placed twice its focal length away from the object on one side and the plate holder is that same distance.

When the object is focussed by the first cylinder, only the vertical dimension is focussed. So the second, oil-filled lens needs to finish the image in the horizontal plane.

It, too has to image 1:1, otherwise the image will be somewhat anamorphic. Since the distance from the object to the holoplate has been fixed by the first cylinder lens, which is in the middle of the mess, at four times the focal length, (2 X Focal length on each side for 1:1 imaging), this second lens must make the same sized image within the same parameters. Conclusion: This "oil-filled custom optic" must have the same focal length as the first lens.

Magnification = object distance/image distance. If another focal length cylinder lens is used, a position could be found where it does focus an image on the film plane, following the basic lens equation,

1/focal length = 1/object distance + 1/image distance,

but object does not = image distance, so the magnification in this plane will not be 1:1, resulting in anamorphism.

So if the focal lengths of both horizontal and vertical cylinders must be equal, then that implies that a spherical lens would be the solution to pull this off without distorting, which is what I am assuming. Otherwise some "happy accidents" might occur!

Looking at Charley Lysogorsky's thorough review of one-step rainbow set ups in the 1985 Lake Forest Symposium Proceedings, (available from me via this forum in easy to use pdf format) there is a set up illustrated that uses a spherical lens larger than the object to produce a one-step image-plane with the lens in the 1:1 conjugate position. A slit is generated on the lens plane by blocking off portions of it. Reference and object beams are generated with beamsplitters. I would use a plane piece of glass as the beamsplitter, with the stronger transmitted component going to the object.

From practical experience with this type of set up, the pieces of cardboard that are placed on the lens to generate the slit account for the biggest disadvantage to using this set up; they waste what meager object light there is at the lens's aperture. (Without the slit in position, this set up gives a wonderful sort of achromatic image at the holo plane upon reconstruction.) Instead of using pieces of cardboard as the slit maker, the mirrors as suggested in your picture could be substituted, providing two functions, both slit aperture and illuminators.

To get immediate holo-gratification, use a big lens about 6" diameter for a 4" by 5" plate, like a condensing pair from an old-fashioned 4" by 5" enlarger, coupla mirrors, and start playing around!
