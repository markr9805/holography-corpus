Based on this tip & trick by Ed Wesly [http://holographyforum.org/phpBB2/viewt ... ing+angles](http://holographyforum.org/phpBB2/viewtopic.php?t=3746&highlight=measuring+angles)

and the paper described in it (thanks for e-mailing it to me Ed). I decided to write a small c# application to plot the concentric circles to be able to make this simple device easily.

A sample of the generated image can be found here:

[http://ghisays.net/projects/plotter.jpg](http://ghisays.net/projects/plotter.jpg)

The software can be found here:

[http://ghisays.net/projects/AnglePlotter.exe](http://ghisays.net/projects/AnglePlotter.exe)

To use you need to have the Microsoft .NET 2.0 runtime installed in your computer.

if you don't have it you can download it here:

[http://www.microsoft.com/downloads/deta ... laylang=en](http://www.microsoft.com/downloads/details.aspx?FamilyID=0856EACB-4362-4B0D-8EDD-AAB15C5E04F5&displaylang=en)

If anyone is interested in the source code e-mail me and I will reply with it.

Any feedback is appreciated.

Regards,
