I was doing a little searching and found this laser diode.

[http://www.intelite.com/diode.htm](http://www.intelite.com/diode.htm)

What I like about this, if it is holographically sound, is it spreads the wavelengths further apart for color DCG holography using the red shift method. Right now I have used 457 and 514 wich is only a 57nm spread, thus the reason of ony using two wavelengths not three. If I could use a 408 wavlength with a 457 and a 514 then I should be able to get blue, green and red and possible shift a little more to the red. I used Kaveh's CIE diagram ( [http://holographyforum.org/phpBB2/viewt ... 24&start=0](http://holographyforum.org/phpBB2/viewtopic.php?t=3624&start=0) ) and found the following.

408 + 80 = 488 - Light blue

457 + 80 = 537 - Green

514 + 80 = 594 - Orangish-Red

What would be even better is

use the 408 diode for swell to Light Blue

use the 442 HeCd for swell to Green

use the 533 DPSS for swell to Red. (this would be redder the using the 514 with an 80nm shift).

All 120V non water cooled lasers.
