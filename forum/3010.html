I'm currently using an 40x objective to spread beam for my single beam reflections. My table space is quite limited though. So after looking on Ebay I've spotted a 100x objective on auction.

Anyone know if a 100x objective will work? Would the beam diverging so sharply have any negetive effects on my hologram?

Also anyone got any good tip for cleaning up dirty objectives?
JohnFP Fri Jan 07, 2005 11:53 am #2
I would advise against a 100x objective for the reference beam. For object illumination it would be fine. If you are making single beam reflections you can use the Z axis of your table to gain distance, that is, use an ovehead lighting geometry. See the first drawing. This gains about 30 - 50 % more distance. Then if you really want more distance wrap the expanded beam then shoot it overhead as in the second drawing. Both of these set ups only require front surface mirrors which are not that expensive. The second drawing is how I have my single beam set up configured. Also with the ovehead lighting geometry you can stand you object up or lay it down to get the correct overhead reference angle. This comes is quite handy with some objects. I have my ovehead mirror mounted on a modified photographic enlarger pole. This allows variable height, tilt and swing.

Most objectives can be dismantled and cleaned. I have alway found that somehow the space between the lenses is where the "dirt" is. You probably need a spanner wrench to unscrew the ringe that holde the lenses in. You need to look at your actual type of objective. Then clean the lenses, with the roll method and many q-tips. I always use methanol (Dry Gas for cars) first then acetone. I have been able to clean objective to the point the expanded beam almost looks as good as that from a spatial filter, but it takes practice and patients.

Dinesh Fri Jan 07, 2005 4:38 pm #3
Three problems I see with a 100X objective are light loss, the ability to pinhole and the extreme divergence of the referece. A 100X will severly cut down on the light because of the large spread causing long exposures. Assuming that the beam is spread by theta degrees, the beam radius at a distance r is rtan(theta), so the area of the circle covered by the beam is pi(r^2)(tan^2(theta)). If you have a laser of power, W, then the power/unit area is W/(pi(r^2)(tan^2(theta))). Putting in some numbers, let's say the lens diverges the beam by 70 degrees (it'll probably be more in a 100X) and you have a 5mW laser about 1 meter away, then the power/unit area on the plate is 0.0003 mW/sq cm or 0.3 nW/sq cm.

The pinhole for this objective will be minute. A 40X requires a 5 micron, so a 100 will probably require a 1 micron, which may be difficult to find (although John has a way of making his own that may work for you). This can be calculated if you know the numerical aperture of the lens.

The extreme divergence of the beam will require an equally extreme diverge to reconstruct the hologram. If you view the hologram with a collimated or narrow-divergence light source, you'll get distortions.

[edit: the radius at r is rtan(theta/2). oops!]

HoloM Fri Jan 07, 2005 6:06 pm #5
I found that cleaning microscope objectives is often a never ending story.

You need to dissassemble the whole unit, in order to clean every lens. but you only see if it is clean enough when you have assembled it again and spread a laserbeam. I never got it so clean to see no fringes. So I useed only one double concave lens, with a focal length of about 6mm.

You can clean it easily with a q-tip. while spreading a beam and see the result immediatly. Pay attention with acetone! Some lenses to have a non reflective coating. If you clean these with acetone, it's possible to wipe the expensive coating away!! An other solution is to use the objective and a pinhole. There you need not clean the objective so much, you only need to position the pinhole in the right position. And if you use the right size of pinhole, you get a very clean beam. I would not recommend to use a 100x objective, because of much loss of light.
