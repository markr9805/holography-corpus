Hi Joe,

I just converted the first jpg of the document you just posted to a PDF, using IrfanView.

The resulting file size came out at 530k, which is smaller than the original jpg.

I used the default setting in IrfanView and disabled password security in the PDF check box.

IrfanView is free for none commercial use and can be downloaded here:

[http://www.irfanview.com/](http://www.irfanview.com/)

There is also a wiki page on the software:

[http://en.wikipedia.org/wiki/IrfanView](http://en.wikipedia.org/wiki/IrfanView)

Oh, and there is no annoying advertisement on the the page.

HTH,

Steven.
