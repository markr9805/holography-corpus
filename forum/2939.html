<rant>

I don't claim to be an expert in the use of the web, but does anyone else here make their living on internet sales? I do. While my knowledge of the latest code has fallen years behind, I try to write code that can be viewed on any computer that can surf the web (webtv is another matter, but I get orders from those users too), even if it's running windows 3.11. That's become more difficult as the standards change, but all our code is done by hand, clean and short as possible. Where'd all the bandwidth go? Things like big fat css references that could have been handled with under 100 characters, pointless java, etc. It shouldn't take a 50k file to load a page that says "click here".

It seems to me that the site, while cool-looking in a browser that can see it (I can see it in my non-preferred browser, Netscape 7 [aka: "monkeydung"], yes, it's been cool looking all along), violates one of the basic tenets of sales: <B>Don't do anything that prevents customers from buying.</B> If you want to sell stuff to fat people, you don't make them climb a 12 foot rock wall to get to it.

So I need to install the latest Flash plugin? Why? YOU want to SELL to ME (or anybody, anywhere). I shouldn't have to do anything but give you money, it's your job to figure out how to get it, not how to NOT get it. If the flying clowns stop people from getting to the merchandise, it's time to fire them.

I can understand wanting the site to be "cutting-edge", but the only time that it's logical for a site to be cutting edge is when that's what you're selling ("cutting-edge"). If you want my sister, who's got a little money but the brains of a can of Alpo, to buy anything, you'll be out of luck. Remember, not everyone is a techie, and plenty of Windows users are afraid to install anything new that isn't absolutely essential.

Ok, so it works on your machine, and I can get it to work on my machine. What about the rest? I sell to a broad cross section of society, ages from pre-teen to 70+, poor folks to district court judges and actual scientists, and looking at my site platform report, all manner of computer users.

Platforms recorded in our recent stats include: Win XP, Win 98, Win 2000, Win ME, Mac PPC, Mac 68k, Win 95, Win NT, Linux x86, WebTV, Win Server 2003, Linux, Win 3.1, Sun OS, Amiga, Unix, BeOS, CP/M-80, FreeBSD, FreeBSD x86, NetPliance, OS/2, Open BSD, QNX, RISC OS, and Nokia Web Telephone.

So, why do you need to watch out for too much Flash? Because if it stops people from buying from a sales oriented site, it's a bad thing, no matter how cool it looks.

Ok, so enough of my stupid opinion, I've only spent about fifteen years selling various crap, and the rest making it.

Nice work Danny, sorry about the rant. It seems like you made a site for holographers, while the real object is to sell to the masses (more or less). Make it easy for them.

I have a couple of other suggestions:

That "grey screen" thing remains a problem, but will only be solved by:

A. Getting that referring host to slightly alter the frames code they use - my preferred browser isn't that old.

B. Getting an actual hosted domain, as I've noted before. Should be doable for under $20/month, I think ours is about $26/mo and we've got secure forms processing, SSL, and other stuff. See comment below. Paying for domain hosting is like paying for shoes - it's worth it.

Build a FAQ. If I send model horse folk, they're going to ask questions that shouldn't need to be answered more than once or twice, like "How much to make a hologram of my model horse", "How much to make a hologram of my real live horse", and "Can you put a hologram ON my model horse". Building a FAQ will help keep Dinesh from going insane when the "elves" ask the same asinine questions over and over.

Build a "suggestion box". This to shunt the "You should do X" comments off to a list that's easy to read, manage, and ignore if need be, and helps keep the number of site related emails down. It looks like ipowerweb.net, who appears to be hosting 4s-c.org, could handle the domain and provide the server side processing to cover all that, and apparently for cheap. I only write server-side code for NetCloak, but I imagine they've got some samples that could be adjusted.

Oh, and bury any email addresses in code, preferably using a form that sends to the server which THEN sends the email. Email addresses are gleaned by robots and can result in upwards of 300 spam emails per day (like I get!).

That's all I can remember right this second. What's that "store" part going to be? Shopping cart? Paypal related? Host based? Paying for an external card processor? (hope not)

Some of this might seem like it should be sent through private emails, but I'm doing it here because there's bound to be people more expert than I who might chime in where it would be valuable.

-Gary
