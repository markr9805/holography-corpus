I am sure this has been documented somewhere but I wonder why such a simple technique is not commonly used in making SBR holograms.

That is, simply place a polarizing sheet on the object side of the plate oriented to the polarization of the reference beam such that only light off the diffusing object that is polarized in the correct direction makes it back through the plate to interfere with the reference light. Of course we could then greatly increase the light striking the ojbect to approach the limits of H1 to H2 reflection holograms.

I know when I finally get back into the lab, I will be trying this straight away. I need to find a very rigid, preferably glass, abosorbtion polarizer.

Any thoughts?

JohnFP Tue Mar 04, 2008 4:12 pm #4
Hey Tony, No H1 to H2, a Single Beam Reflection with kicker mirrors for additional lighting.

You basically set up a Single Beam Reflection and use kicker mirrors to add additional light to to the object. Then you take the polarizer and place it on the plate (or very near to) between the plate and object (object side). Make sure the polarizer is letting the most reference beam light through and you will know that it is oriented correctly. It will then allow only the correctly polarized light bouncing off the diffusion object to pass through to the plate to create the fringe structure. You should be able to add considerable additional kicker lightint without noise or fogging.

zipsister Fri Mar 07, 2008 4:35 pm #12
Hi all,

As with all SBR holograms the catch 22 situation is finding a way to reduce the light intensity that strikes the plate (reference beam) while have a brighter light reflecting from the object all from one beam. A simple solution is to place a small neutral density filter a small distance out from the diverging reference beam so that is casts a dimmer 'shadow' beam onto the reference side of the plate. The brighter spill over light on both sides of the neutral density filter is caught by mirrors placed on either side of the hologram and diverted back to the object which then reflects this brighter light to the plate where it interfers with the dimmer reference beam. As such, the light ratio is increased in favour of the object.

Zipsister

zipsister Sat Mar 08, 2008 8:07 am #15
Personally I never make SBR holograms using glass that is the same size as the sheet of holographic film; I only ever use glass that is much bigger for that very reason; to avoid any shadows from the glass edging.

And if you want an extra bright background for your object place behind it a mirror with frosted glass or a piece of motled shower screen angled directed back at the film; i.e. you have the film sandwiched between glass then the object then the frosted glass/shower screen then the mirror. Obviously the mirror/frosted glass combo are much larger than the object to accomodate the large parallax.
