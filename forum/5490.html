Hi everyone,

Although I've had much experience with electronics, holography is relatively new for me.

I have recently set up an inteferometer on the tiled floor with no optical isolation table, and expanded the beam so that the fringe pattern is on a 30cm x 30cm viewing board. When there are no fans running, and noone is walking about, the fringes stay absolutely still.

Is this an indication that the current setup should be okay for holography? Or should I expand the fringe pattern further so that even smaller movements are detectable?

Thanks.
Colin Kaminski Fri Apr 14, 2006 1:26 pm #2
It sounds like you are going to be OK. While you have the interferometer set up you may wish to play a little. First make sure there are no reflections entering the laser by tilting everything slightly. Then try to allign the beams as colinearly as posible until you get a bulls eye pattern from the interferometer. This is a sensitive as you can make it. It's a fun experiment. If you just want to crash ahead and make some holograms cool!

Post some pictures if you can.
